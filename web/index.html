      Modelos por perfil

      Herdar usa o modelo selecionado na conversa. Um modelo configurado aqui tem precedência nesse perfil.

      Até dois subagentes executam em paralelo, com consumo adicional de tokens. Implementar usa uma worktree Git ou cópia, executa verificações com as aprovações configuradas e devolve uma proposta para revisão. Não tem shell genérico nem MCP.
